
# User Stories (sample)

- As a vendor, I want to add new inventory lots so I can track expiry dates and quantities. (FR-2.4)
- As a vendor, I want to record a sale and automatically decrease inventory so I never oversell. (FR-4.2, NFR-3)
- As a vendor, I want to see customers with outstanding crate balances so I can collect them. (FR-5.1)

# Roadmap (suggested phases)
1. MVP: Inventory, Customers, Transactions basic CRUD + printing statements.
2. Phase 2: Crate ledger, FEFO visualization, offline sync.
3. Phase 3: AI Forecasting integration, advanced reporting, authentication.
