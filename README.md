
# PGVMS - Perishable Goods Vendor Management System

Repository skeleton containing:
- `backend/` - Go HTTP REST API (Postgres) deployable to Google Cloud Run
- `frontend/` - React Native app skeleton
- `infra/` - Cloud Build config and sample migration
- `docs/` - SRS, API spec, ER diagram (SQL), user stories, roadmap

This is a starter scaffold. Fill environment variables and run migration before starting.
